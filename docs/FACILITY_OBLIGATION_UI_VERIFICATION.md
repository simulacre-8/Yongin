# 시설·법 의무사항 화면 연결 검증

**기준일:** 2026-09-06

## 원인

시설과 시설별 의무 매핑은 Supabase에 적재돼 있었지만, `/obligations` 화면이 기존 `demo-data.ts`의 용인시청 1건과 정적 의무 10건을 사용하고 있었다. 따라서 사용자가 보기에는 시설 DB와 법 의무사항이 비어 있는 것처럼 보였다.

## 원격 데이터 기준선

| 항목                                |  건수 |
| ----------------------------------- | ----: |
| 관리대상 전체                       |   153 |
| FMS 시설                            |   150 |
| 시연 전용 대상                      |     3 |
| 공중이용시설·공중교통수단 화면 대상 |   151 |
| 대상–의무 매핑                      | 2,929 |
| 매핑된 고유 의무                    |    84 |
| 의무가 1건 이상인 대상              |   151 |

용인경전철은 FMS 시설물이 아니라 공중교통수단이며 적용 의무 5건이 연결돼 있다. 고기상수도는 적용 의무 31건, 일반 교량·옹벽·터널 다수는 19건이 연결돼 있다.

## 화면 확인

`/obligations` 목록에서 `Supabase 시설 151건`, 미입력 151개소, 각 대상별 적용 의무 건수가 표시되는 것을 1600×900 화면과 브라우저 DOM에서 확인했다. 대표 행은 `(신)수포교 19건`, `고기상수도 31건`, `용인경전철(에버라인) 5건`이다.

선택한 대상의 상세 화면은 `ref_managed_target_obligation`과 `ref_obligation`을 결합해 의무분류, 관계법령·근거, 의무사항, 이행시기를 표시하도록 변경했다.

## 상세 클릭 검증

브라우저에서 `고기상수도` 행을 선택했다. 상세 제목이 `법 의무사항 시설물`, 대상이 `고기상수도`로 전환됐고, 원격 매핑 31건이 다음 세 그룹으로 나타났다.

- `①시설물안전법`: 긴급안전점검, 안전조치, 성능평가, 유지관리계획 등
- `②중대재해처벌법`: 개선·시정, 관계법령 의무이행, 예산, 인력배치, 점검결과 조치 등
- `③개별관계법령`: 수도법상 상수도관망·수도시설 관리와 수질검사 등

각 행에는 관계법령·근거와 이행시기 입력 컨트롤이 표시된다. 이는 시설 DB와 법 의무사항이 실제 화면까지 연결됐음을 확인하는 표본이다.
