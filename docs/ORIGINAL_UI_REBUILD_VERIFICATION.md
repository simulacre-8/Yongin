# ADOMS 원본 UI 재구성 검증 기록

**검증일:** 2026-09-06

## 범위

적용범위 판정은 선행 화면으로 유지하고, 이후 시연 라우트 `/dashboard`, `/targets`, `/laws`, `/obligations`, `/evidence`, `/inspection`, `/summary`를 `ADOMS_데모작업 명세.zip`의 SCR 화면 구조에 맞춰 재구성했다.

## 시각 검증 결과

| -------------- | ------------------ | -------------------------------------------------------------------------------------- |

## 공통 UI

- 용인특례시 로고, 검정 GNB, 회색 기반 LNB·본문, 핑크 활성 강조, 얇은 회색 격자선으로 원본 정보 구조를 통일했다.
- 이전 클라이언트 요청에 따라 경영목표/PPT형 상단 배너는 복원하지 않았다.
- GNB 이동 후 LNB 자동 접힘과 원형 토글 복원 동작을 유지했다.
- 용인시청 단일 관리대상과 Supabase 연결 상태 표시를 유지했다.
- 전역 15px 확대 규칙을 제거하고 각 원본형 화면에 정의된 7~42px 계층을 그대로 사용한다. 세부 크기와 예시는 `FONT_SIZE_SPEC.md`에 기록했다.

## 다음 단계

클라이언트가 다시 제공할 이미지 파일명을 기준으로 화면별 여백·라벨·상태 변형을 픽셀 단위로 추가 조정한다. 원본 이미지로 확인되지 않는 신규 화면이나 동작은 임의 제작하지 않고 컨펌 대상으로 분리한다.

## 상호작용 표본 검증

- `/targets` 목록에서 `용인시청` 행 선택 시 URL을 유지한 채 SCR-028~029 형식의 기본정보·세부정보 전체 폼으로 전환됨을 브라우저에서 확인했다.
- 기준일자, 사업장·부서, 인원 현황, 업무 담당자, 관리감독자, 첨부파일, 목록 복귀 및 저장 컨트롤이 렌더링되며 원본 글씨 크기에서 표 구조가 유지됐다.

- `/obligations`의 용인시청 행 선택 시 SCR-035 형식의 법·시행령·의무사항·이행시기 계층표로 전환됨을 확인했다. 월 입력과 상·하반기 선택, 초기화, 저장 컨트롤이 노출되며 원본 글씨 크기에서 표 헤더와 행 그룹이 구분된다.

- `/inspection`에서 용인시청과 10개 항목이 선택된 SCR-089 취합 대상 설정을 확인하고 `취합 시작`을 실행했다. 이어 SCR-088 형식의 10개 점검 아코디언과 첫 항목 7열 표가 나타났으며 상태·점검내용만 편집 가능하게 분리됐다.

## 컬러 기준

검정 GNB는 원본형 정보 구조와 대비를 위해 유지했다. GNB 아래의 본문 배경, 검색 패널, 표 헤더, 읽기 전용 영역은 중성 회색 계열로 통일했고, 활성 메뉴·선택 라디오·주요 버튼·집계 강조는 용인특례시 핑크 계열로 통일했다. 오류·경고·이행 상태처럼 의미가 있는 상태색은 식별성을 위해 별도로 유지했다.

## 최종 시각 상태

글씨 원복 후 `/dashboard`를 1600×900과 1366×768에서 재확인했다. 카드 사이 22px 간격이 유지되고 겹침이 없으며, 일반 카드 보더 2px와 기한초과 보더 4px가 적용됐다. 검정 GNB, 회색 업무 배경·패널, 핑크 활성 메뉴·수치·선택 단계·저장 버튼은 그대로 유지된다.
