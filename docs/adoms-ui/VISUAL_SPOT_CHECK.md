# ADOMS UI 시각 표본 검증

**검증일:** 2026-09-06

## SCR-027 — 관리대상 선택

원본 `027_관리대상 현황 – (사업장, 부서) 관리대상 선택.png`는 2001×1127 데스크톱 화면이다. 좌측 연녹색 LNB, 상단 검정 GNB, 회청색 검색 패널, 흰색 입력 블록, 2분할 입력현황 카드, 낮고 조밀한 데이터 표가 확인된다. 큰 KPI 카드나 퍼센트 그래프 중심 화면이 아니며, 분석 문서의 **고밀도 행정시스템 복제 기준**과 일치한다.

## SCR-089 — 점검 취합 대상 설정

원본 `089_이행점검 및 조치 – (사업소, 실·국) 사업장 이행점검.png`는 2001×1127 데스크톱 화면이다. 상단 검색줄 아래에 `사업장명`과 `항목`의 좌우 선택 목록이 있고, 원형 토글로 대상을 고른 후 우하단 `취합 시작`으로 진행한다. 화면 번호는 SCR-088 뒤지만 업무 순서는 **SCR-089 → SCR-088 → SCR-090**이라는 분석과 일치한다.

## 판정

두 표본 모두 카탈로그·영역 보고서·통합 Flow Map의 핵심 해석과 일치했다. 구현 시 원본의 검정 마스킹/가림 영역은 최종 배경 디자인으로 해석하지 않고, 확인 가능한 LNB·검색 패널·표·버튼 구조를 기준으로 삼는다.
