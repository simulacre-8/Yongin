# 용인시 ADOMS 데모 폰트 크기 스펙

**기준일:** 2026-09-06

**상태:** 초기 용인시 브랜드 톤 복원 후 통일 규격

**폰트:** 영문·숫자 `Inter`, 한글 `Noto Sans KR` fallback

## 기본 원칙

영문과 숫자는 Inter의 다양한 굵기를 사용하고, Inter에 없는 한글 글리프는 Noto Sans KR로 렌더링한다. 글자 크기는 기능별로 아래 여섯 단계만 사용한다. 강조는 크기를 갑자기 키우지 않고 굵기와 용인시 마젠타·퍼플 색으로 표현한다.

| 단계      | CSS 크기 | 기본 굵기 | 용도                                              | 화면 예시                                                    |
| --------- | -------: | --------: | ------------------------------------------------- | ------------------------------------------------------------ |
| Technical |     10px |   400–600 | 시스템 한계·식별자·원천 버전·법적 고지의 부가정보 | 규칙 ID, source version, `최종 법적 판단이 아님`의 보조 문장 |
| Caption   |     12px |   400–600 | 메타정보·도움말·파일 제한·보조 설명               | 조직명, 기준일, `개당 10MB 이하`, 읽기 전용 안내             |
| Body      |     14px |   400–700 | GNB·LNB 메뉴, 표 본문, 폼 라벨·입력값, 버튼       | 상시근로자 수와 `120`, 관리대상명, 법령 표, 저장·검색 버튼   |
| Section   |     16px |   600–750 | 카드·패널·표 섹션 제목                            | 담당 중대재해 대상, 시기도래, 알림, 안전인력 확보 표 제목    |
| Product   |     20px |   700–800 | 제품명·큰 메뉴 블록                               | 좌측 화면명 블록, 시스템 제품명                              |
| Page      |     28px |   700–800 | 화면의 한 개 대제목                               | 용인시청 법 적용범위 1차 판정, 이행점검(사업장)              |

| 화면 영역                      | 적용 규격                                                                                     |
| ------------------------------ | --------------------------------------------------------------------------------------------- |
| 검정 GNB                       | 메뉴 14px, 사용자 조직 12px, 사용자명·역할 선택 14px                                          |
| 좌측 LNB                       | 화면명 20px, 그룹 14px, 메뉴 14px, 현재 관리대상 라벨 12px·선택값 14px                        |
| 적용범위 판정                  | 페이지 제목 28px, 패널 제목 16px, 입력 라벨·값 14px, 근거 본문 12px, 규칙 ID·원천 메타 10px   |
| 이행현황                       | 카드 제목 16px, 건수·일반 본문 14px, 표·필터 12–14px, 전체 이행률은 14px로 과대 강조하지 않음 |

## 버튼

기본 버튼은 `120×36px`, radius `8px`를 기준으로 한다. 주 버튼은 퍼플→마젠타 그라데이션과 흰 글씨, 보조 버튼은 흰 배경·연보라 보더·퍼플 글씨를 사용한다. 버튼 글자는 14px·600~700이며 아이콘 때문에 텍스트 크기를 별도로 바꾸지 않는다.

## 예외와 금지사항

10px는 시스템 식별자와 원천 추적처럼 시연자가 직접 조작하지 않는 기술 정보에만 허용한다. 관리대상명, 인원수, 면적, 날짜, 검색조건, 상태, 파일명 등 업무 판단에 쓰는 값은 최소 12px이며 기본은 14px이다. KPI 숫자·상태 수치·총 건수는 색과 굵기로만 강조하고 20px를 초과해 별도 시각 체계를 만들지 않는다.

반응형 구간에서도 본문 글자를 임의로 키우거나 줄이지 않는다. 표가 좁아지면 글자를 축소하는 대신 가로 스크롤을 사용한다.
