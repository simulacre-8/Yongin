# 용인시 ADOMS 데모 폰트 크기 스펙

**기준일:** 2026-09-06  
**상태:** 전역 글씨 확대 오버라이드 제거 후, 각 원본형 화면에 정의된 크기 사용

## 이행현황 시각 검증

이행현황은 1600×900과 1366×768에서 확인했다. 두 해상도 모두 담당대상·시기도래·기한초과·이행률·알림·확보의무 패널 사이에 22px 간격이 유지되며 겹침이나 접촉이 없다. 일반 카드 보더는 6px에서 2px로, 기한초과 강조 보더는 8px에서 4px로 줄였고 카드 모서리는 18px로 정리했다.

## 공통 기준

모든 수치는 브라우저 확대율 100%에서의 CSS 픽셀(`px`) 기준이다. 전역 최소 글자 크기 강제 규칙은 제거했으며, 아래 값은 각 화면의 원본형 CSS 또는 인라인 스타일이 실제로 지정한 값이다.

| 영역 | 현재 크기 | 화면 예시 |
|---|---:|---|

## 전체 소스 정적 분포

현재 활성 화면과 공통 스타일의 명시적 크기 분포는 **7px부터 42px**까지다. 가장 많이 사용되는 값은 12px 76회, 11px 50회, 10px 45회, 13px 33회, 9px 31회다. 이 수치는 중복 선택자와 반응형 규칙을 포함한 정적 출현 횟수이며, 화면 요소 개수와 동일하지는 않다.

## 검토 시 선택 가능한 조정 방식

1. **현재 원본값 유지:** 이번 복원 상태를 그대로 사용한다.
2. **최소 글자만 보정:** 7–9px만 10px 또는 11px로 올리고 표·레이아웃은 건드리지 않는다.
3. **업무 본문만 보정:** 표 본문·입력값의 10–12px를 12–13px로 올리되 제목과 KPI는 유지한다.
4. **화면별 선택 보정:** 적용범위, 관리대상, 실적증빙 등 지정 화면에서 지정 요소만 조정한다.

이번 변경에서는 **1번 상태로 복원**했으며, 사용자가 확대할 요소를 지정하기 전까지 전역 최소 글자 크기를 다시 적용하지 않는다.
