# 용인특례시 브랜드 컬러 적용 근거

**확인일:** 2026-09-05

용인특례시 공식 홈페이지와 공식 헤더 로고에서 다음 색상을 확인해 시연 UI의 전역 CSS 토큰으로 적용했다.

| 용도 | 색상 | 근거 |
|---|---|---|
| 주조색 마젠타 | `#DF3355` | 공식 홈페이지 CSS의 가장 빈번한 강조색 |
| 로고 퍼플 | `#A93193` | 공식 헤더 로고 대표 색상 |
| 로고 청록 | `#16BAA0` | 공식 헤더 로고 대표 색상 |
| 딥 퍼플 | `#5E3682` | 공식 헤더 로고와 보조 UI 색상 |
| 네이비 | `#003675` | 공식 홈페이지 CSS의 정보·텍스트 강조색 |
| 연분홍 | `#F7DFF1` | 공식 홈페이지 민원행정 서비스 배경 그라데이션 |
| 아이보리 | `#FBFBDC` | 공식 홈페이지 민원행정 서비스 배경 그라데이션 |
| 본문 잉크 | `#1E2124` | 공식 홈페이지의 고대비 본문·헤더 색상 |

공식 홈페이지: https://www.yongin.go.kr/index.do  
공식 CSS: https://www.yongin.go.kr/resources/site/www_2026/css/main_2026.css  
공식 공통 레이아웃 CSS: https://www.yongin.go.kr/resources/site/www_2026/css/main_layout.css

## 시각 검증

대시보드, 관계 법령, 점검 총괄표를 1600×1000 데스크톱 화면에서 확인했다. 공식 로고, 마젠타 활성 상태, 퍼플 메뉴, 청록 완료 상태, 연분홍–아이보리 배경이 공통 셸과 데이터 화면에 일관되게 적용됐고 텍스트 대비와 표 판독성을 유지했다.
