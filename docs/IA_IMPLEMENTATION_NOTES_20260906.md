## 확인된 IA

기능 IA는 장기 메뉴 후보를 제안하는 참고자료다. **현재 데이터가 연결되지 않은 기능이 많으므로 IA 전체를 구현 기준으로 사용하지 않는다.** 이번 용인 데모의 GNB는 검수용 임시 순서인 `홈 → 이행현황 → 관리대상 현황 → 의무사항 → 의무이행 → 이행점검 → 설정`만 적용하며, 메뉴명과 중처법 프로시저는 다음 검수 단계에서 다시 확정한다.

현재 `설정` 화면에는 실제로 동작하는 대상 프로필 사실값만 둔다. `적용범위 판정`은 설정에서 저장된 값을 읽어 ADOMS 승인규칙 31개 중 시연용 4개 규칙의 판정 결과와 근거를 표시한다. 조직도·담당자, 법령 예외 및 사유이력 등 데이터가 없는 기능은 이번 단계에서 만들지 않는다.

기능 IA의 공공 앱 색상 토큰은 배경 `#F5F6F8`, 표면 `#FFFFFF`, 텍스트 `#1B2330`, 보조 텍스트 `#495468`, 선 `#E3E7ED`, 고객 앱 주조색 `#1D6FA3`, 주조색 연한 배경 `#E7F1F8`이다. 사용자 요청에 따라 이번 UI 정리에서 마젠타 중심 강조를 남색·블루 중심으로 전환하고 용인 로고의 마젠타는 로고 자체에만 남긴다.

## 홈 상세 집계 데이터 가용성

원본 SCR-011/012/015/016은 의무 대분류·하위 점검사항과 대상 또는 실·국·본부를 피벗한 4상태 집계를 사용한다. 이행률 계산 시 `해당없음(NA)`은 분모에서 제외한다. 다만 현재 Supabase 조직은 `용인특례시`, `시민안전관` 두 행뿐이며 업무 대상 152건이 모두 시민안전관에 연결돼 있다. `기획조정실`, `행정국`, `중대재해예방팀` 조직 마스터 및 대상·의무 배정 데이터는 없다. 중처법 대표 의무 14건은 `parent_obl_id` 하위 의무가 없고 `detail_ko` 법령 상세문장만 보유한다. 대표 의무 ID에 대한 `v_facility_workflow` 업무 행도 현재 없다.

따라서 실제 부서별 수치와 임의의 하위 점검항목을 생성하지 않는다. 1차 UI는 의무의 `detail_ko`를 1번 세부 점검사항으로 표시하고, 부서별 셀은 `미배정`으로 명시한다. 실제 집계는 향후 조직 마스터, 조직-대상 또는 조직-의무 배정, 하위 점검사항 마스터가 제공된 뒤 연결한다.
