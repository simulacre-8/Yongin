# UI 우선 수정 시각 메모

**확인일:** 2026-09-06

## 적용범위 판정

1600×900에서 GNB 하단의 굵은 핑크 선이 제거됐고, GNB 글자는 14px로 보인다. 왼쪽 메뉴는 자동으로 접히지 않으며 `#090909` 바탕 안에 밝은 둥근 컨테이너로 묶인다. 프리셋 명칭은 14px, 120명·39,872㎡ 등 값은 10px의 진한 글자로 표시된다. 기준값 복원은 오른쪽 아래에 120×36px, 흰색·`#A93193` 보더, radius 8px로 표시된다.

## 원본 SCR-006 이행현황

원본은 왼쪽 LNB 뒤에 검정색 바탕이 있고, 연녹색의 큰 둥근 내부 컨테이너가 있다. 본문은 상단의 대상·기한 카드 3개, 하단의 이행률 그래프와 연도·대상별 표, 오른쪽 절차 안내로 나뉜다. 카드 간에는 분명한 간격이 있으며 일반 박스 테두리는 얇고, 기한초과 카드만 붉은 강조 테두리를 사용한다. 현재 구현의 박스 접촉·과한 테두리는 이 구조를 기준으로 다시 정리한다.

## 이행현황 교정 결과

1600×900에서 중앙 `시기도래/기한초과` 행과 아래 `전체 이행률` 패널 사이에 18px 간격이 확보되어 박스가 더 이상 붙지 않는다. 일반 패널 보더는 1px, 기한초과 보더는 2px로 줄였다. 상단 3열과 오른쪽 알림·확보의무 카드의 모서리·간격이 분리되고, 원본 SCR-006의 고밀도 표 구성을 유지하면서 이전의 과도하게 큰 제목·수치·필터·표 글자를 단계적으로 낮췄다.

## 이행현황 2차 교정

1600×900에서 담당 중대재해 대상·시기도래·기한초과의 제목 크기를 동일하게 맞췄다. `총 1개소`, `총 2건`, `1개월 이내`, `1주일 이내`, `오늘 마감`, 각 `0건`은 크기를 과장하지 않고 동일 위계에서 주조색만 사용한다. 기한초과 보더와 건수는 `#A93193`으로 통일했다. 전체 이행률 제목·수치·연도·대상 필터는 검정 구분선 위 한 줄 헤더로 재배치했다. 우측 알림·안전보건 확보의무의 제목 아래 선은 `#090909`이며, 의무 카드의 1·2·3·4 원형 번호를 제거하고 내부를 회보라 `#F3EFF4`로 통일했다.

## 시설 DB 화면

`/targets`의 시설물 탭에서 Supabase 원격 데이터를 조회해 FMS 시설 150건과 대상별 적용의무 건수가 표시된다. 관리대상명·분류·주소·적용의무·데이터 출처 열이 정상 렌더링되며 공중교통수단과 도급·용역·위탁은 별도 탭으로 분리됐다.
