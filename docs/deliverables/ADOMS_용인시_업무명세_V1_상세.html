01 · EXECUTIVE SUMMARY

납품 범위 요약

본 업무는 기존 ADOMS 화면·업무 흐름을 참고해 용인특례시 영업 시연에 필요한 범위만 React/Vite와 hosted Supabase로 재구성한 프로젝트입니다. 화면 시연에 그치지 않고 법령·시설·조직·업무·이행·증빙·점검 값이 실제 데이터베이스와 Storage에 남도록 구현했습니다.

3,688용인시 관련 전체 의무풀
153참조 관리대상
2,929시설·의무 매핑
2,891내 업무 런타임 항목
최종 결과물: https://sapa-yongin.netlify.app · GitHub main과 hosted Supabase가 연결된 상태이며, 정민하 전무가 저장소와 DB 접근권한을 보유하고 있어 모든 산출물을 정본에서 직접 인수할 수 있습니다.

05 · WBS REBASELINE

변경 WBS 반영

클라이언트 공개 WBS의 최초 기준선은 전체 41개 작업과 총 31시간의 압축 실행 일정으로 작성됐습니다. 이는 가격 산정을 위한 인력 타임시트가 아니라 화요일 시연까지의 작업 순서표입니다. 실제 구현 과정에서는 고객 제공 데이터와 반복 검수 결과를 반영해 아래와 같이 재기준화했습니다.

변경영역 기존 WBS 최종 반영 효과
GraphDB/API 외부 Graph API 수령을 P0로 계획 외부 API 없이 Supabase RDB에 필요한 ADOMS 식별자·법령·의무를 투영 신규 GraphDB 구매·개인 PC 서버 없이 시연 가능
데이터 범위 핵심 50~150개 중심 클라이언트 CSV 전체 의무풀 3,688건과 대상별 매핑 2,929건 적재 실제 필터·시설별 의무 조회 가능
시설 구분 대표 대상 3개 FMS 150 + 공중교통수단 1 + 도급/용역 2를 출처 구분하여 관리 경전철을 공중교통수단으로 분류
내 업무 기존 이행현황·점검 페이지 공식 조직도 792단위와 2,891개 업무를 연결한 별도 런타임 구축 자동·수동 배정과 위임·완료·초기화 실데이터
의무이행 단일 조치일·증빙 업무구분 5종, 기록구분 3종, 이행기간, 문서요약, Word 양식, 반복 사건으로 확장 차수별 로그·증빙·CSV 추적
배포 프런트 선배포 후 환경 점검 Netlify의 공개 Supabase 변수 누락을 가드하고 build-info로 커밋 추적 다른 PC·일반 브라우저에서도 DB 조회
대외 표기: 이 시스템은 제한된 정본과 대상 프로필을 바탕으로 한 규칙 기반 적용 가능성 및 업무관리 시연입니다. 법률 자문이나 용인시 전체의 최종 법적 의무 확정을 대신하지 않습니다.

08 · SCOPE BOUNDARY

범위 및 가정

구분 내용 대외 표현
시연 목적 프로필·사실값 변경 시 검수된 규칙에 따른 적용 가능성 후보와 근거 경로를 보여줌 최종 법률 판단이 아닌 1차 후보 판정
법령 범위 고객 제공 전체 의무풀 3,688건은 검색·조회하며 자동 판정은 시연용 실행규칙 범위 전체 DB 조회와 자동 판정 범위를 구분
사실값 상시근로자·연면적·대상여부 등은 필드별 출처·기준일·가정 여부를 구분 가상 데이터 또는 출처 표시
Graph DB 이번 시연은 GraphDB 없이 hosted Supabase RDB로 구현 실시간 외부 GraphDB 연동은 범위 밖
미확인 항목 수범주체 미판정·조건 미구조화·시행일 미확인은 unknown/보류 적용·비적용으로 자동 단정하지 않음
완료 기준 저장·재조회·증빙 다운로드·이력·초기화·배포 재현성을 검증 전체 화면 수가 아닌 핵심 시연 흐름 기준
범위 밖 항목: 운영용 실명 인증·인사시스템 연동, 전 기관 전수 법률검수, 외부 GraphDB 운영, 전자결재·알림·바이러스 검사, 상용 SLA는 이번 영업 시연 납품에 포함하지 않습니다. 필요 시 별도 요구사항·견적으로 진행합니다.
